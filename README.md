#TEJEBONITO🧶

##Descripcion 
TEJEBONITO es un emprendimiento 
dedicado a la elaboración de
productos tejidos a mano mediante
la técnica de crochet.
Nuestro propósito es ofrecer
productos creativos, hechos con 
dedicación y pensados para 
diferentes gustos y necesidades.

##¿Qué ofrecemos?
En TEJEBONITO ofrecemos productoa 
hechos a mano como:
-Cintillos
-Marcápáginas
-Posavasos
-Amigurumis

##Proposito
Ofrecer productos de crochet
hechos a mano, creativos y únicos,
elaborados con dedicación para brindar
opciones especiales a nuestros clientes.
